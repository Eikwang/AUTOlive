# 前端美化手动测试清单

对应计划：`frontend-beautification-plan.md`（T8 验证任务）

启动方式：`python webui.py` 后浏览器访问 webui 地址。

## 1. 标题层级统一

- [ ] 三级配置页面顶部标题为 20px 加粗（所有功能页面一致）
- [ ] 配置分组卡片标题为 16px 加粗
- [ ] 功能列表分组头部标题为 15px 加粗
- [ ] 输入框/下拉框的浮动 label 为 12px 灰色，不再有大有小

## 2. 按钮样式统一

- [ ] 所有操作按钮圆角一致（8px），字重一致（500）
- [ ] 内部按钮使用 primary 蓝色，无混用旧灰色
- [ ] 运行/停止按钮：运行中红色、停止时绿色
- [ ] 主题切换按钮为扁平样式（flat），不再有背景块

## 3. 输入框统一

- [ ] FormField 创建的输入框默认 250px 宽
- [ ] 显式传入 width 的输入框宽度正确解析（如 width:400px）
- [ ] 传入 min-width 时不再误匹配为 width
- [ ] 输入框圆角一致（8px）

## 4. 主题切换

- [ ] 浅色模式：页面背景浅灰、卡片白色、文字深灰
- [ ] 切换深色模式后：背景/卡片/文字颜色全部跟随变化（无残留白色块）
- [ ] 左侧导航栏在深色模式下正常显示
- [ ] 导航栏顶部标题区为纯色专业蓝（不再是紫色渐变）

## 5. 导航交互

- [ ] 分组选中状态：左侧蓝色边条 + 浅蓝背景
- [ ] 功能项选中状态同上，悬停有浅色背景反馈
- [ ] 搜索结果页正常渲染，图标/文字颜色统一
- [ ] 配置加载失败时显示红色错误 + 重试按钮

## 6. 回归确认

- [ ] 修改任一输入框内容后出现"配置已保存"通知
- [ ] 全局搜索配置项功能正常
- [ ] 功能启用/禁用开关正常工作
- [ ] 数据分析等含按钮的页面按钮仍可点击
