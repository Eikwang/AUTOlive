# 字幕与内置播放器接入指南

> 来源：audio_player / captions_printer 整合（2026-09-25，/autoplan 批准）。
> 错误文案锚点：R1 设备失败 → 本文 §2；R8 ffmpeg → 本文 §4。

## 1. 开启字幕（三步）

1. 前端「基础功能 → 字幕打印」打开**启用**开关（保存即时生效，无需重启）。
2. 首次使用需**重启主系统**（播放器/字幕模块随主系统启动加载）。
3. 复制页面显示的**字幕页地址**（`http://<api_ip>:<api_port>/captions`；host:port 来自 config 的 `api_ip`/`api_port` 键，`api_ip=0.0.0.0` 时页面回显为 `127.0.0.1`），在 OBS 中添加「浏览器」源粘贴。
   - 双机直播：把地址里的 `127.0.0.1` 换成本机局域网 IP（dx8）。
   - OBS 叠加需要页面背景透明：页面背景色保持 `none`（默认）。

**无 OBS 本地自测**：直接在浏览器打开字幕页地址，主系统播一句 TTS，页面应逐句浮现字幕——验证通过后再进 OBS。

**断线自检**：字幕页与主系统断连时页内自显「字幕服务未连接」（OBS 源里直接可见）；OBS 刷新/重连后自动恢复并回显当前样式与开关状态。

## 2. 输出设备选择（内置播放器）

「基础功能 → 音频播放」选**内置播放器**后出现设备下拉：
- 枚举失败/无声卡：显示"未检测到音频设备，将使用系统默认"。
- 播放时设备打开失败：自动**回退系统默认设备**，控制区错误条会显示设备列表与 `audio_player.device_index` 配置指引——将 `config.json` 中 `audio_player.device_index` 改为期望设备号（`-1` = 系统默认），保存后下一条播放即生效（无需重启）。

## 3. 播放队列与插队

- 待播队列按 `audio_player.priority_mapping` 优先级插入（数值越大越先播；未识别类型排队尾）。UI 只读展示；调整直接改 `config.json`（dx7 逃生门）。
- **插队仅重排待播顺序，不打断当前正在播放的音频**（预期管理）。需要打断当前：控制区「跳过当前」按钮。
- 暂停/续播：控制区按钮；暂停期间字幕同步挂起（恢复后继续）。

## 4. 依赖

- 内置播放器：`pyaudio`（声卡）、`pydub`（解码非 wav，**需要 ffmpeg 在 PATH**——R8：解码失败报错请检查 ffmpeg 安装）。
- 字幕页：浏览器/OBS 浏览器源，无额外依赖。
- 以上均已在 runtime312 环境预装（零新增 pip 依赖）。

## 5. 故障排查

| 现象 | 排查 |
|---|---|
| 字幕页显示"字幕功能未开启" | 开关未打开（开启即时生效，无需重启） |
| 字幕页显示"字幕服务未连接" | 主系统未运行或地址错误；检查 api_ip/api_port |
| 控制区错误条"字幕推送失败（连续 3 次）" | 字幕页断开/OBS 源关闭；恢复后自动续推 |
| 有声音无字幕 | 确认 enable 已开 + OBS 源地址正确 + 音频播放器为 builtin/外部模式均可 |
| 播放无声 | 控制区错误条查看设备错误；§2 回退默认设备 |
