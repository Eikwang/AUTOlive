# 参数生效语义矩阵（D-20 中枢工件）

> 生成：/autoplan 批准批次实施期（2026-10-19）。方法论：每参数标注【生效语义｜默认值｜读取时机】，读取时机以代码证据为准（file:line）；未盘点的键在实施触碰时**必须补行**（A6 守卫：webui 写入未登记键时告警）。
> 写者矩阵约束（前置）：main 进程可达时 webui 直写 config.json 会被静默覆盖——运行期改值一律走 `*-config` 窄端点或重启生效项。

## 生效语义分类

- **即时**：运行期读 config，改后下一次消费即生效（无需重启）
- **重连生效**：页面构建时读，浏览器重连/刷新后生效
- **需重启**：仅在进程启动编排时读，改后必须重启对应进程
- **仅启动读取**：子进程/托管组件启动时构建，改后需重启该组件
