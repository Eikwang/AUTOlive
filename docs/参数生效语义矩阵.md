# 参数生效语义矩阵（D-20 中枢工件）

> 生成：/autoplan 批准批次实施期（2026-10-19）。方法论：每参数标注【生效语义｜默认值｜读取时机】，读取时机以代码证据为准（file:line）；未盘点的键在实施触碰时**必须补行**（A6 守卫：webui 写入未登记键时告警）。
> 写者矩阵约束（前置）：main 进程可达时 webui 直写 config.json 会被静默覆盖——运行期改值一律走 `*-config` 窄端点或重启生效项。

## 生效语义分类

- **即时**：运行期读 config，改后下一次消费即生效（无需重启）
- **重连生效**：页面构建时读，浏览器重连/刷新后生效
- **需重启**：仅在进程启动编排时读，改后必须重启对应进程
- **仅启动读取**：子进程/托管组件启动时构建，改后需重启该组件

## 音频播放设计勘误摘要（2026-10-22 审查批次，权威裁决记录）

> 完整版见工作区 docs/音频播放设计勘误-20261022.md（docs/* 白名单制下不入库，本地留存）。

1. **设计项 6 废弃（uc1a）**：保留播放器配置与 builtin 内置播放器（固定 pygame 将废止 2026-09-24 批准的插队/暂停/续播资产）。
2. **设计项 5 语义修订（uc2a）**：out_path 保留为透明临时目录，仅移除用户可配置性（前端输入框退役，后端键内部使用）。
3. **队列溢出规则精化（Eng F-1+实施复推）**：「取代末尾同权重」权威化为——同权重组组首（最老）取代+组内 FIFO；满队高优插入驱逐**最低优组组首**；999 单实例约束优先。测试锚：tests/test_audio_playback_review.py::TestQueueFourRules（四示例+主叙述逐行）。
4. **info_to_callback 移除零损失证实**：/callback 端点仅日志、wait_play_audio_num 恒 0 从未写入（死链）。
5. **开关豁免范围（A11/F-7）**：EDTalk 推送链豁免仅限 TTS 链类型；本地音频类维持 enable 门控。
6. **999 时序规格（spec C1）**：暂停条目播放器持有不重入队；打断者播毕即续播不等排空；暂停期新到一律排队（含第二条 999 舍弃）；回退 1 秒=输出采样率帧数。
