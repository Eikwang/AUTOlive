# 参数生效语义矩阵（D-20 中枢工件）

> 生成：/autoplan 批准批次实施期（2026-10-19）。方法论：每参数标注【生效语义｜默认值｜读取时机】，读取时机以代码证据为准（file:line）；未盘点的键在实施触碰时**必须补行**（A6 守卫：webui 写入未登记键时告警）。
> 写者矩阵约束（前置）：main 进程可达时 webui 直写 config.json 会被静默覆盖——运行期改值一律走 `*-config` 窄端点或重启生效项。

## 生效语义分类

- **即时**：运行期读 config，改后下一次消费即生效（无需重启）
- **重连生效**：页面构建时读，浏览器重连/刷新后生效
- **需重启**：仅在进程启动编排时读，改后必须重启对应进程
- **仅启动读取**：子进程/托管组件启动时构建，改后需重启该组件

## 窄端点盘点（A6 前置）

现有控制面 POST 端点：`/sys_cmd`（run/stop/restart/factory）、`/danmaku/send`、`/danmaku/send-results`、`/danmaku/send-status`（DanmakuListener O2 批次）。**无通用参数写窄端点**——运行期参数修改当前依赖：webui 进程内 Config.set+save（即时类参数两进程各自读自身消费点，跨进程参数存在双 Config 形态已知约束——config_get 双形态兼容）。A6 守卫：webui 写入未登记本矩阵的键时打日志告警（实施于 config_auto_save.auto_bind 路径，随批落地）。
