### 环境补丁清单（Step 0 实测沉淀，重装机必做）

```bat
D:\AI\runtime312-clone\python.exe -m pip install ^
  pytorch_lightning faster_whisper cn2an g2p_en wordsegment ^
  openai-whisper jieba x-transformers peft gradio torchcodec ^
  split_lang opencc-python-reimplemented
D:\AI\runtime312-clone\python.exe -m pip install "fast_langdetect==0.3.2"
```

1. **jieba_fast shim**：py3.12 无 jieba_fast wheel。在
   `runtime312-clone\Lib\site-packages\jieba_fast.py` 放别名模块（import jieba 并
   注册 `sys.modules["jieba_fast"]`/`["jieba_fast.posseg"]`）。若未来装上真
   jieba_fast，删除该文件即可。
2. **fast_langdetect 锁 0.3.2**：GPT-SoVITS 的 LangSegmenter 需要 `infer` 子模块
   API（0.3.2 有，1.x 已移除）。split_lang 安装会把它拉高，装完 split_lang 后必须重锁。
3. **split_lang detector 单行适配**：
   `split_lang/detect_lang/detector.py` 的
   `fast_langdetect.detect(text, model="full")` 改为
   `fast_langdetect.detect(text)`（0.3.2 无 model 参数）。重装 split_lang 后需重做。
4. **torchcodec**：torch 2.11 音频加载走 torchcodec（缺它 TTS 500 报
   "TorchCodec is required"）。
5. **users.pth 不再被依赖**（P1-2）：GPT-SoVITS 子进程的 PYTHONPATH 由
   `utils/autolive_paths.py` 启动器注入（6 条路径清单与原 users.pth 一致）。
   runtime312-clone 里如仍存在 users.pth 可删除验证。

## 5. 常见失败对照

| 症状 | 原因 | 修复 |
|---|---|---|
| `No module named 'pytorch_lightning'` 等 | 补丁清单未执行 | 重跑第 2 节 pip 命令 |
| `fast_langdetect has no attribute 'infer'` | 版本被 split_lang 拉高 | 重锁 0.3.2（清单第 2 条） |
| `detect() got unexpected keyword 'model'` | split_lang 适配被重装覆盖 | 重做清单第 3 条 |
| `TorchCodec is required` | 缺 torchcodec | 清单补装 torchcodec |
| `端口 9880 已被占用`（外部进程文案） | 外部程序或旧版外部 GPT-SoVITS | 结束占用进程，或 `gpt_sovits.hosted=false` |
| 胶囊置红（连续 3 次失败） | 服务反复崩溃 | 状态条"重启"按钮（清零）；日志尾看根因 |
