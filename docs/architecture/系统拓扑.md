## 数据流向

```
直播弹幕 ──▶ DanmakuListener（进程内 12 平台引擎）
              ├── 弹幕/礼物/进场 ──▶ 对话链（my_handle：LLM 回复）
              │                         ├── 回复文本 ──▶ TTS（GPT-SoVITS 子进程 9880）
              │                         │                 └── 音频 ──▶ EDTalk realtime serve（推 16kHz）
              │                         │                              └── 口型视频流 ──▶ 直播推流
              │                         └── 音频 ──▶ RVC 变声（rvc_adapter，可选）
              ├── 点赞/统计 ──▶ 计数路径（答谢/积分）
              └── 系统事件（ENGINE_STATUS 登录生命周期）──▶ WebUI notify
```

## 关键事实

- **主系统解释器**：EDTalk `runtime312`（`启动程序.bat` 的 `RT=D:\AI\EDTalk\runtime312`，含 pytest 测试环境）
- **GPT-SoVITS 专用解释器**：`runtime312-clone`（`utils/autolive_paths.py:55`），与 EDTalk 环境隔离
- **进程内 vs 子进程**：DanmakuListener 进程内运行（无 8765 端口、引擎崩溃不拖垮主程序，per-engine 隔离+服务级守护）；GPT-SoVITS/RVC 为 ManagedProcess 托管子进程（hosted=false 可关闭）
- **EDTalk 数字人**：外部项目（D:\AI\EDTalk），AUTOlive 通过 `utils/edtalk_realtime/edtalk_client.py` HTTP 推送音频（单飞行句+背压+错误透传三段式）
- **训练链路**：训练主播（`utils/train_streamer/pipeline.py`，runtime312 解释器）/训练声音（`utils/train_voice_pipeline.py`，runtime312-clone）
- **GPU 优先级**：直播关键路径（EDTalk 推理/TTS/变声）> 背景任务（翻唱/音频训练），探测条件见 `docs/designs/audio-integration-voice-pipeline.md` Constraints 节
