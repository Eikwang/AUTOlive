# 知识库撰写指南（本地问答 / 助播知识库）

> 适用范围：**本地问答**（数字人侧，`local_qa` 配置节）与**助播知识库**
> （`assistant_anchor.local_qa` 配置节）。两者自 2026-10-27 收敛批
> （/autoplan main-20261026-214845）起共用同一套匹配引擎与知识库结构，
> 本文的写法对两边通用。

## 一、两个知识库分别在哪生效

| | 本地问答（数字人侧） | 助播知识库 |
|---|---|---|
| 配置节 | `local_qa.text` / `local_qa.audio` | `assistant_anchor.local_qa.text` / `audio` |
| 配置页 | 本地问答页 | 助播页 |
| 生效条件 | LLM 通道选「本地问答」（chat_type=local_qa）；LLM 失败时也作托底 | 助播页勾选「AI对话」（弹幕）或「聊天」（聊天页消息） |
| 回答由谁说 | 数字人（勾选 AI对话/聊天 时改由助播说） | 助播（独立音色，本地外放） |
| 匹配顺序 | 音频 → 文本 | 音频 → 文本 → 本地问答 → LLM |

两条线互不干扰：助播知识库未命中会落到本地问答，再未命中走 LLM。

## 二、文本知识库：格式与写法

**格式：一问一答 TXT，每行一条 `问题|答案`**（英文竖线分隔，UTF-8 编码）：

```
怎么点歌|发送 点歌+歌名 就可以哦
主播多大了|这是秘密，猜猜看？
你好|你好呀[欢迎回来|又见面啦]{username}
```

### 语法特性

1. **多问一答**——同一答案写多行，每行一个问法：
   ```
   怎么点歌|发送 点歌+歌名 就可以哦
   如何点歌|发送 点歌+歌名 就可以哦
   点歌|发送 点歌+歌名 就可以哦
   ```
2. **变量替换**：
   - `{username}` = 提问用户的名字
   - `{cur_time}` = 当前时间
3. **随机括号** `[选项1|选项2|选项3]`——命中后随机取一个，回复不重复：
   ```
   主播多大了|[这可是秘密哦|猜猜看|永远18岁]
   ```
   括号里的 `|` 是选项分隔符，**不参与**「问题|答案」的切分——问题和答案里都可以放心用括号。
4. **精确优先**——与词库完全相同的问题（忽略空格、全角/半角、大小写差异）直接命中，不走相似度评分。

### 匹配算法

```
相似度 = max(字符相似度, 分词相似度 × 长度惩罚)
```

- 字符相似度：difflib（归一化后逐字符对比）
- 分词相似度：jieba 分词后的词集合交并比 × 词数长度惩罚——让"怎么听歌"能对上
  "怎么点歌"这类同构问法（纯字符对比以前对不上）
- 词条在文件加载时预分词并缓存（修改文件即自动失效重载），单条查询毫秒级

**阈值**（页内"最低相似度"，默认 0.6）：

| 现象 | 调整 |
|------|------|
| 不相关的问题也命中（误命中） | 调高（0.7-0.8） |
| 明明写了的问题没命中（漏命中） | 调低（0.5 左右） |

标定参考：同义/同构问法普遍 0.73+，无关句普遍 0.43-，0.6 为安全分界。

### 撰写习惯建议

- 重要问题写 2-3 个问法变体（口语化、缩写、带语气词各来一条）
- 答案用随机括号增加自然感
- 空行、没有 `|` 的行会被自动跳过（日志计数），不用怕格式脏
- **改完保存即生效**（文件改动自动感知），不用重启系统

## 三、音频知识库：格式与用法

把音频文件（**mp3 / wav / flac / m4a / ogg**）放进"音频存储路径"的目录，
**文件名（去掉扩展名）就是"问题"**：

```
out/本地问答音频/
  ├── 主播今天吃什么.mp3      ← 问"主播今天吃什么"命中，直接播放
  ├── 感谢老板.wav
  └── 芜湖起飞.flac
```

**匹配档位**（页内下拉）：

| 档位 | 行为 |
|------|------|
| 包含关系 | 精确匹配 + 互相包含（弹幕含标题、或标题含弹幕；同时命中取标题更长更具体的） |
| 相似度匹配 | 精确 + 包含 + 相似度兜底（阈值用"音频最低相似度"） |

- 归一化后匹配：全角/空格/大小写差异不影响命中
- 音频**优先于文本**：音频命中直接播放该文件，不做 TTS
- 音频库适合放固定梗的录音、音效类回应；通用问答交给文本库

## 四、历史差异说明（老用户须知）

| 旧认知 | 实际情况（2026-10-27 收敛批查明并修复） |
|--------|------------------------------------------|
| "自定义 json"是一种 JSON 匹配格式 | 从未解析过 JSON——两种格式走同一个管道行加载器，属格式幻影，下拉已退役 |
| 写了词库就能命中 | 匹配器调用了一个不存在的方法，**完美命中也匹配不到**；本地问答页的路径键还与代码读取位置分裂——均已修复 |
| `[1|2]` 随机语法可用 | 渲染时方法名写错一直静默失效，已修复 |
| 音频匹配开关 | 本地问答页的音频匹配此前无消费链（配置零读取），已接通 |

存量配置自动迁移（系统启动时幂等执行）：格式键清理、顶层遗留路径键并入
text 子节、音频档位键补默认——无需手动改配置。
