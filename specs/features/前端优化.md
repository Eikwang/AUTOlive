# 前端优化 — 功能需求说明书

## 1. 背景与价值

**为什么做**：当前前端界面简陋，功能区域杂乱，各种输入框、选项铺满页面，没有启用的功能不会折叠，影响用户体验。

**做成什么样**：采用简约现代的苹果风格，深色/浅色可切换主题，左侧导航栏 + 三级页面布局，功能清晰分组，配置项规整美观。

---

## 2. 范围

### 本次做

- 左侧导航栏 + 三层级页面布局
- 深色/浅色主题切换
- 功能分组（基础功能、直播选项、互动设置、AI对话、高级功能、系统设置、运行状态、色彩模式）
- 功能启用/禁用开关
- 配置项自动保存（文案类需手动保存）
- 搜索功能（实时显示结果）
- 导航栏可折叠（展开显示图标+文字，收窄只显示图标）
- 系统状态显示（运行/停止）
- 导航栏状态持久化到配置文件

### 本次不做

- 移动端适配
- 自定义主题颜色
- 配置项验证

## 4. 需求详述

### 4.1 核心流程

1. 用户打开前端，看到左侧导航栏（功能分组）+ 右侧内容区
2. 点击左侧功能分组，中间显示该分组下的功能列表（二级页面）
3. 点击功能列表中的功能项，右边显示该功能的配置页面（三级页面）
4. 修改配置项后自动保存（文案类需点击保存按钮）
5. 通过搜索框快速定位配置项
6. 点击系统状态按钮运行/停止系统
7. 点击色彩模式按钮切换深色/浅色主题

### 4.2 交互规则

- 功能未启用时完全隐藏配置项，启用后才显示
- 配置修改后立即保存（文案类需点击保存按钮）
- 搜索实时显示结果，高亮匹配关键字
- 主题切换即时生效，保存到本地
- 导航栏可折叠，状态保存到配置文件

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 功能禁用时保留配置内容，启用后恢复 |
| BR-002 | 主题切换保存到 localStorage，刷新后保持 |
| BR-003 | 导航栏状态保存到配置文件，手动切换才生效 |
| BR-004 | 文案类配置需点击保存按钮，其他配置自动保存 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 左侧导航栏显示功能分组
  - **Given** 用户打开前端
  - **When** 页面加载完成
  - **Then** 左侧导航栏显示 8 个功能分组（基础功能、直播选项、互动设置、AI对话、高级功能、系统设置、运行状态、色彩模式）

- [ ] **AC-002**: 三级页面布局
  - **Given** 用户点击左侧功能分组
  - **When** 点击"直播互动"
  - **Then** 中间显示该分组下的功能列表（弹幕过滤、礼物答谢、积分系统、关键词映射等）

- [ ] **AC-003**: 功能启用/禁用
  - **Given** 功能列表中显示"积分系统"开关
  - **When** 用户点击开关启用"积分系统"
  - **Then** 右侧显示积分系统的配置页面

- [ ] **AC-004**: 功能禁用时隐藏配置
  - **Given** "积分系统"已启用，显示配置页面
  - **When** 用户点击开关禁用"积分系统"
  - **Then** 右侧配置页面隐藏，但配置内容保留

- [ ] **AC-005**: 深色主题切换
  - **Given** 用户在浅色主题下
  - **When** 点击主题切换按钮（月亮图标）
  - **Then** 界面切换为深色主题（深灰背景 + 浅色文字）

- [ ] **AC-006**: 主题保存到本地
  - **Given** 用户切换为深色主题
  - **When** 刷新页面
  - **Then** 页面仍显示深色主题

- [ ] **AC-007**: 搜索功能
  - **Given** 用户在搜索框输入"积分"
  - **When** 输入完成
  - **Then** 显示匹配的功能项和配置项，高亮显示"积分"关键字

- [ ] **AC-008**: 搜索结果跳转
  - **Given** 搜索结果显示"积分系统"
  - **When** 用户点击"积分系统"
  - **Then** 跳转到积分系统的配置页面

- [ ] **AC-009**: 系统状态显示
  - **Given** 系统未运行
  - **When** 页面加载完成
  - **Then** 左侧导航栏底部显示绿色背景 + "运行系统"按钮

- [ ] **AC-010**: 系统运行/停止
  - **Given** 系统未运行
  - **When** 用户点击"运行系统"按钮
  - **Then** 系统启动，按钮变为红色背景 + "停止运行"

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-011**: 导航栏折叠
  - **Given** 导航栏处于展开状态
  - **When** 用户点击折叠按钮
  - **Then** 导航栏收窄为只显示图标模式，状态保存到配置文件

- [ ] **AC-018**: 导航栏展开/收窄切换
  - **Given** 导航栏处于收窄状态（只显示图标）
  - **When** 用户点击展开按钮
  - **Then** 导航栏展开显示图标+文字，状态保存到配置文件

- [ ] **AC-012**: 配置保存失败
  - **Given** 用户修改配置
  - **When** 保存失败
  - **Then** 显示错误提示，配置回滚到修改前状态

- [ ] **AC-013**: 搜索无结果
  - **Given** 用户输入不存在的关键字
  - **When** 搜索完成
  - **Then** 显示"未找到匹配项"提示

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-014**: 功能禁用保留配置 ← BR-001
  - **Given** "积分系统"已配置
  - **When** 用户禁用"积分系统"
  - **Then** 配置内容保留，下次启用时恢复

- [ ] **AC-015**: 主题持久化 ← BR-002
  - **Given** 用户切换为深色主题
  - **When** 关闭浏览器后重新打开
  - **Then** 页面仍显示深色主题

- [ ] **AC-016**: 导航栏状态持久化 ← BR-003
  - **Given** 用户将导航栏收窄为只显示图标模式
  - **When** 关闭浏览器后重新打开
  - **Then** 导航栏仍显示为只显示图标模式

- [ ] **AC-017**: 文案配置手动保存 ← BR-004
  - **Given** 用户修改文案配置
  - **When** 点击保存按钮
  - **Then** 配置保存成功，按钮旁边显示"已保存"提示
