# 伴奏闪避 — 功能需求说明书

## 1. 背景与价值

**为什么做**：点歌模式双轨链路中，伴奏在独立线程播放、人声进入口型推理。前奏/间奏窗口期间系统会插播其它音频（弹幕回复、礼物答谢、播报等），但伴奏此时仍保持全音量，实际直播中把播报内容盖住，观众听不清插播在说什么。

**做成什么样**：前奏/间奏窗口内消费其它音频时，伴奏音量自动降为原音量的 50%，插播播完立即恢复；歌曲人声不触发闪避。播报清晰、伴奏听感自然。

---

## 2. 范围

### 本次做

- 双轨点歌模式下，前奏/间奏窗口内插播音频（非歌曲音频）时，伴奏音量降为原音量的 50%；
- 插播音频播完后伴奏立即恢复原音量；窗口内连续多条插播时全程保持压低，最后一条播完才恢复；
- 歌曲人声（唱歌部分）播放期间伴奏始终保持原音量，不触发闪避；
- 闪避比例固定 50%，不加配置项、不加前端界面。

### 本次不做

- 配置项与设置界面 — 用户明确决定固定 50%，实播后如需调整再评估；
- 唱歌期间高优先级打断消息的闪避 — 严格限定触发范围为前奏/间奏窗口；
- 数字人未激活的整轨播放模式 — 该模式歌曲以完整混音单轨播放，无独立伴奏，闪避不适用；
- 播报侧音量与伴奏默认音量的调整 — 本功能仅改变闪避期间的伴奏音量。

## 4. 需求详述

### 4.1 核心流程

> 主线路径全局视角，细节由 AC 承载。

1. 点歌触发 → 伴奏以原音量起播，人声切片进入数字人口型推理（现状不变）；
2. 前奏/间奏窗口内插播其它音频（弹幕回复、答谢、播报等非歌曲音频）→ 伴奏音量降为原音量的 50%；
3. 插播音频播完 → 伴奏立即恢复原音量；连续多条插播则保持压低到最后一条播完；
4. 唱歌人声正常播放期间 → 伴奏始终原音量，不闪避。

### 4.2 交互规则

- 闪避的压低与恢复对观众听感应当连贯（无爆音、无长时间静默），恢复时机以插播音频播完为准；
- 闪避只作用于伴奏声道，插播音频与人声音量不做任何补偿或调整。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 闪避触发范围严格限定为前奏/间奏窗口内消费的非歌曲音频；歌曲人声音频不触发闪避 |
| BR-002 | 闪避量为伴奏原音量的 50%（固定值，不可配置） |
| BR-003 | 闪避恢复时机为插播音频播完之时；窗口内连续多条插播期间持续保持压低 |
| BR-004 | 任何异常路径与手动停止/切歌路径下，闪避状态不得残留（不得悬挂在 50%） |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 前奏窗口插播触发闪避
  - **Given** 点歌模式开启且歌曲处于前奏窗口
  - **When** 窗口内插播一条播报音频
  - **Then** 播报开始时伴奏音量降为原音量的 50%，播报内容清晰可辨

- [ ] **AC-002**: 间奏插播播完后立即恢复
  - **Given** 间奏窗口内插播的播报正在播放（伴奏已被压低）
  - **When** 播报播完
  - **Then** 伴奏音量立即恢复到原音量

- [ ] **AC-003**: 连续多条插播持续压低
  - **Given** 窗口内连续有多条播报接连消费
  - **When** 多条播报连续播放
  - **Then** 整段连续播报期间伴奏保持 50%，直到最后一条播完才恢复原音量

- [ ] **AC-004**: 唱歌人声不触发闪避
  - **Given** 歌曲人声（唱歌部分）正常播放
  - **When** 人声各段接连播放
  - **Then** 伴奏始终保持原音量，不触发闪避

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-005**: 纯前奏/纯间奏不误压
  - **Given** 窗口内没有任何播报消费（纯前奏/纯间奏）
  - **When** 窗口正常经过
  - **Then** 伴奏全程保持原音量

- [ ] **AC-006**: 异常路径不得悬挂压低状态
  - **Given** 播报音频播放中出现异常（如音频加载失败）
  - **When** 异常路径发生后
  - **Then** 伴奏不得停留在压低状态（闪避必须恢复，不得悬挂在 50%）

- [ ] **AC-007**: 手动停止/切歌后新歌按原音量起播
  - **Given** 播报正在压低伴奏播放
  - **When** 用户在前端点击停止播放或触发切歌
  - **Then** 伴奏停止或新歌起播，且新歌伴奏按原音量起播，不残留闪避状态

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-008**: 闪避只影响伴奏 ← BR-001, BR-002
  - **Given** 任何情况下闪避生效
  - **When** 伴奏被压低
  - **Then** 仅伴奏音量变化（降为原音量的 50%），歌曲人声与播报音频的音量均不受影响
