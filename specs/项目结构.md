## 2. 核心模块功能说明 (Module Description)

### 2.1 入口文件

| 文件 | 功能 | 职责 |
|------|------|------|
| **main.py** | 主程序入口 | 初始化配置、启动平台监听、语音对话 |
| **webui.py** | Web UI 入口 | 调用frontend模块化结构，启动NiceGUI界面 |
| **frontend/main.py** | 前端主入口 | AIVtuberApp类，模块化WebUI应用程序 |
| **config.json** | 主配置文件 | 所有功能的配置项 (300+) |

### 2.2 前端模块 (frontend/)

#### 配置模块 (frontend/config/)
| 模块 | 功能 | 核心类/函数 |
|------|------|-------------|
| **settings.py** | 配置管理 | `init_config()`, `get_config()` - 配置读取和写入 |
| **paths.py** | 路径管理 | `get_base_path()`, `get_config_path()` - 路径处理 |

#### 工具模块 (frontend/utils/)
| 模块 | 功能 | 核心类/函数 |
|------|------|-------------|
| **common.py** | 通用工具 | `textarea_data_change()` - 文本区域数据转换 |
| **helpers.py** | 辅助函数 | `ProgramManager`, `SystemCommand` - 程序管理 |
| **audio.py** | 音频工具 | 音频处理相关功能 |

4. **可扩展性**：模块化设计便于添加新功能和扩展
5. **可维护性**：每个模块专注于单一职责，便于维护和调试

这种架构设计使得项目具有良好的可扩展性和可维护性，能够支持持续的功能迭代和优化。
